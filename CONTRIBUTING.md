# Contributing to EndlessRunner-UE5

First off, thank you for considering contributing to EndlessRunner-UE5! It's people like you that make this project better.

## How Can I Contribute?

### Reporting Bugs
* Check the existing issues before opening a new one.
* Use a clear and descriptive title for the issue.
* Describe the exact steps which reproduce the problem.

### Suggesting Enhancements
* Check the roadmap in the README for planned features.
* Open an issue with the tag "enhancement" to discuss your idea.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure the project builds and runs without errors in Unreal Engine 5.2+.
4. Issue that pull request!

## Style Guide
* Follow [Unreal Engine Coding Standards](https://docs.unrealengine.com/5.2/en-US/epic-cplusplus-coding-standard-for-unreal-engine/).
* For Blueprints, maintain clean node layouts and use comment boxes to group logic.
* Prefix assets correctly (e.g., `BP_` for Blueprints, `T_` for Textures, `SM_` for Static Meshes).
